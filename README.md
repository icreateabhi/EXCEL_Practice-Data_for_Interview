📊 **Excel Interview Practice — From Basic Formulas to Interview-Level Problems**

I’ve been consistently practicing Excel for Data Analyst / MIS roles, and recently I worked on a set of interview-oriented problems using real-world style datasets.

Here are some of the concepts I practiced:

🔹 **Q24 — Multiple Conditions Lookup**
Employee ID + Month → Actual Sales
• INDEX-MATCH with multiple conditions
• Understanding `*` as AND
• Understanding why `1` is used in MATCH

🔹 **Q25 — SUMIFS**
Employee + Region → Total Sales

🔹 **Q26 — COUNTIFS**
Employee + Attendance Status → Number of Present days

🔹 **Q27 — SUMIFS with Multiple Conditions**
Employee + Region → Total Sales

🔹 **Q28 — AVERAGEIFS**
Employee + Region → Average Sales

🔹 **Q29 — COUNTIFS with Date Range**
Employee + Present Status + Start Date + End Date → Attendance Count

🔹 **Q30 — SUMIFS with Date Range**
Employee + Start Date + End Date → Total Sales

🔹 **Q31 — XLOOKUP with Multiple Conditions**
Employee ID + Month → Actual Sales

🔹 **Q32 — Target vs Achievement**
Target + Actual Sales → Achievement % and Status

One thing I’m learning from this practice is that Excel interviews are not only about remembering formulas.

The important part is **identifying the pattern behind the question**:

➡️ Total → SUMIFS
➡️ Count → COUNTIFS
➡️ Average → AVERAGEIFS
➡️ Lookup → XLOOKUP / INDEX-MATCH
➡️ Multiple conditions → Combine conditions
➡️ Date range → `>= Start Date` and `<= End Date`
➡️ Business logic → IF / IFS

I’m continuing to practice these patterns with different datasets so that I can solve problems based on logic rather than memorizing formulas.

**Learning every day. Improving one question at a time. 💪📈**
